# Проверка версии 0.1 — 27 октября 2026

Проверено в текущей Windows-среде с Linux-контейнерами Docker Desktop.

- Собраны и запущены пять контейнеров: app, scanners, harvester, spiderfoot, phoneinfoga. Основной контейнер проходит healthcheck.
- Команды Maigret 0.6.0, Sherlock 0.15.0, Holehe 1.61, theHarvester (6790b147), SpiderFoot 4.0 и PhoneInfoga 2.11.0 прошли локальные проверки запуска. Проверены используемые CLI-флаги Maigret и Sherlock.
- Реестр содержит 18 интеграций; 16 выполняют условия запуска. GeoLite требует локальную MMDB, AbuseIPDB — отсутствующий ключ.
- 17 автоматических тестов прошли: серверная логика и преобразование отчётов. Проверка синтаксиса JS и компиляция Python прошли.
- На реальном API IPinfo проверен публичный адрес 8.8.8.8 из примера пользователя: HTTP 200, корректные поля Lite, три узла и две связи в графе, исходный JSON справа.
- В интерфейсе выполнено совместное исследование вымышленного номера +1 202-555-0123: phonenumbers и PhoneInfoga завершились успешно. Поисковые ссылки PhoneInfoga отмечаются сформированными ссылками, а не найденными аккаунтами.
- Проверены история, таблица, выбор источника, панель JSON и окно настроек с 18 карточками. Сохранённые ключи не возвращаются в поля ввода.
- Переданные ключи IPinfo, Etherscan и TronGrid зашифрованы и сохранились после пересоздания основного контейнера. Открытые значения не обнаружены в исходниках и клиентских файлах образа. Ключи Etherscan и TronGrid ещё не проверены внешними запросами.
- Проверено настольное расположение панели справа и адаптация к узкому окну. Снимок: [preview.jpg](preview.jpg).

Это не проверка всех сайтов и модулей сторонних утилит. Проверка полноты, точности и ложных совпадений на пользовательских исследовательских данных ожидает предоставления тестовых объектов. Выполнение образа на отдельной Linux-машине не проверялось; Linux-контейнеры собраны и работают в Docker Desktop.

Ограничения первой версии: фиксированные бесключевые наборы агрегаторов, первые страницы криптоистории, одна сеть Ethereum mainnet, отсутствие встроенной офлайн-карты и фотоинструментов. Полное описание — в [README](../README.md).
