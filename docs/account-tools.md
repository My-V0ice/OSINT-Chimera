# Поиск аккаунтов — версия 0.4

Добавлены пять утилит; всего в каталоге 23. Прежние ключи и история сохраняются. Панель настроек позволяет вводить и заменять новые ключи; сохранение не выполняет внешних запросов. Режим обращения, необходимость ключа, ограничения и примечания видны в карточке утилиты.

| Утилита | Вход | Обращение / бесплатный объём |
|---|---|---|
| [Socialscan](https://github.com/iojw/socialscan) 2.0.1 | Email, ник | Локальная CLI в контейнере обращается к платформам по HTTP; без ключей; лимиты сайтов, максимум 160 секунд |
| [Ignorant](https://github.com/megadose/ignorant) 1.2 | Телефон с кодом страны | Модули Instagram, Snapchat, Amazon; без ключей; по 18 секунд на модуль; до 3 проверок одновременно |
| [WhatsMyName](https://github.com/WebBreacher/WhatsMyName) | Ник | Проверяющий модуль Химеры, GET-запросы к сайтам; без ключей; до 60 сайтов за запуск, 4 потока, 6 секунд на запрос |
| [GitHub Accounts](https://docs.github.com/en/rest/search/search#search-users) | Ник, email, ФИО | HTTPS API: без токена 60 запросов/час на IP, поиск 10/мин; с токеном обычно 5 000/час, поиск 30/мин |
| [Gravatar Profiles](https://docs.gravatar.com/rest/api-data-specifications/) | Email | HTTPS API v3; бесплатный ключ обязателен; по умолчанию 1 000 запросов/час |

Условия источников сверены 27 октября 2026. Часть сайтов использует CAPTCHA или изменённые endpoint: наличие установленного модуля не означает успешного ответа сайта. Подтверждать принадлежность нескольких аккаунтов одному человеку нужно отдельно.

## Обработка

- Socialscan возвращает занятость и допустимость идентификатора. Занятый ник может быть зарезервирован или принадлежать удалённому профилю. CLI сериализует булевы значения строками; адаптер обрабатывает их явно.
- Ignorant запускается через библиотеку без автоматического обновления upstream CLI. Классификация Instagram проверена дополнительно: произвольный JSON с ошибкой не становится находкой. Snapchat требует явного `TAKEN_NUMBER` или `OK`; Amazon — распознаваемого ответа. CAPTCHA и неизвестные форматы означают неопределённость. Адаптер не отправляет SMS, письма восстановления и не подбирает пароли.
- WhatsMyName — база данных, а не готовый сканер. Используется ревизия `35576e909ce4846c769d353f7979d11ac25516b6`, автор Micah Hoffman и сообщество, лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). База загружается при сборке; во время поиска не обновляется. Выборка равномерно чередует social, coding, gaming, blog, music, images и video, до 60 записей. Пропускаются записи с `valid=false`, POST, заявленной защитой и HTTP вместо HTTPS. Проверяются положительные и отрицательные сигнатуры; неизвестная страница не считается отсутствующим профилем. Ревизия, лицензия, число сайтов и результаты всех проверок сохраняются в JSON.
- GitHub: ник — точный endpoint профиля; email и ФИО — публичный поиск первых 30 кандидатов. Закрытый email недоступен. Неполный ответ поиска отмечается; HTTP 403 с исчерпанной квотой считается лимитом, а не неверным ключом. Интервал запросов в приложении 6,1 секунды; фактический остаток читается из заголовков источника.
- Gravatar: trim + lowercase + SHA-256 email; API получает хеш. Показываются профиль и `verified_accounts`, включая сведения о верификации источником. Профиль может отсутствовать для дополнительного email или при отключённой публичности. Используется актуальный API v3 с ключом, без зависимости от legacy API.

В центре показываются только находки и объяснения; отрицательные и неопределённые проверки остаются в правой панели JSON. Если часть проверок завершилась ошибкой, отсутствие находок не обозначается окончательным пустым результатом. Успешный пустой ответ сопровождается плашкой «Ничего не найдено».

## Запуск

`docker compose --profile tools up -d --build`

Новый приватный сервис `accounts` не публикует порт на хост, не получает API-ключи приложения и запускает команды без shell. Socialscan и Ignorant используют раздельные виртуальные окружения. Базы и секреты приложения остаются в прежних томах.

## Проверено 27 октября 2026

49 серверных тестов и 4 теста отображения прошли. Тестируются строковые булевы Socialscan, неоднозначные ответы Instagram и CAPTCHA, сигнатуры и ограничение выборки WMN, фильтрация находок, SHA-256 Gravatar, блокировка при отсутствии ключа, необязательный токен GitHub, обработка квоты HTTP 403 и история новых запусков.

В Docker фактически запущены все три новых сборщика: на вымышленных данных Ignorant вернул 3 проверки, Socialscan — 6, WhatsMyName — 60. Запуски завершились с кодом 0 и частичными результатами: часть платформ ограничивает доступ или возвращает неопределённый ответ, находок по этим тестовым значениям не было. Эти ответы не трактуются как доказательство отсутствия аккаунтов. В браузере GitHub Accounts без токена успешно получил публичный демонстрационный профиль `octocat` и показал данные и JSON. Gravatar проверен автоматическими тестами с подставленным ответом; реальный запрос ожидает ввода пользовательского ключа.
