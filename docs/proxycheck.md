# ProxyCheck.io — версия 0.5.1

Добавлен отдельный инструмент в «IP и геолокация». Проверяется публичный IPv4 или IPv6 через HTTPS API ProxyCheck v3 (`ver=2026-06-24`); соединение с проверяемым IP не устанавливается.

[Условия и схема API](https://proxycheck.io/api/) сверены 2 ноября 2026: без ключа 100 проверок в сутки на исходящий IP, бесплатный ключ даёт 1 000 в сутки. Ключ необязателен и управляется через общую панель настроек. Сохранение ключа не выполняет внешний запрос. Кнопка «Проверить» выполняет проверку фиксированного публичного IP `8.8.8.8` и расходует квоту. Фактические лимиты контролирует ProxyCheck; интервал приложения — 1 секунда, повторные успешные ответы используют общий кэш.

В сводке отдельно показаны proxy, VPN, Tor, хостинг, анонимность, оценки риска и уверенности, провайдер и ASN при наличии. Центральные данные содержат запись проверяемого IP, справа сохраняется полный ответ API. `false` и оценка `0` не скрываются: «Proxy: Нет, VPN: Нет» — полноценный результат. Анонимность не приравнивается к VPN или proxy. Оценки отражают мнение источника и не используются для автоматической блокировки.

Успешный `warning` сохраняет сведения и предупреждение. Отказ, исчерпанная квота, неверный ключ, пропущенные признаки или запись другого IP не интерпретируются как отсутствие VPN. Отсутствующие булевы признаки не заменяются на `false`. Строки `yes/no` старого API v2 не принимаются за ответ v3.

Добавлено 7 тестов: работа без ключа, необязательный ключ, положительные/отрицательные результаты, IPv6, предупреждения, отказы, проверка схемы и полный запуск через API приложения с исходным JSON. Ключи и история используют существующее защищённое хранилище.

Проверка установленной версии: прошли 71 серверный тест и 5 тестов интерфейса. В Docker выполнен реальный запуск через общий API приложения на публичном IP `8.8.8.8` без ключа: статус `completed`, обработанный результат `success`, признаки proxy/VPN получены как `false`, полный JSON доступен. Визуальная проверка браузера не выполнялась.
