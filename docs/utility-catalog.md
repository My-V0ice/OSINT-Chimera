# Каталог утилит — версия 0.3

Концепция изменена 27 октября 2026: приложение объединяет утилиты для разных задач, каждая запускается отдельно. Основной интерфейс: категории и инструменты слева, обработанные данные в центре, JSON справа. Граф и управление исследованиями убраны из интерфейса.

Показываются все непустые поля и записи ответа, включая вложенные значения. Нули и false являются данными. Пустой ответ сопровождается плашкой «Ничего не найдено». Недоступность источника, ошибка авторизации и исчерпание квоты не обозначаются отсутствием результатов. В PhoneInfoga подготовленные запросы остаются отдельным списком для ручной проверки. В Holehe/Sherlock/Maigret отрицательные совпадения не отображаются как находки; полный ответ остаётся в JSON.

Новые вызовы используют `/api/tools/{tool}/runs`. История выбранной утилиты включает её ответы из старых многосоставных поисков. Новый запуск не создаёт исследование и не вычисляет граф. Исторические данные и API предыдущей версии сохранены для совместимости.

До изменения интерфейса создан локальный Git-коммит `ffae3ac`. Файлы `.env*`, секреты, локальная база, временные данные и GeoLite-базы исключены из Git. Подготовленные файлы проверены на совпадения с пятью сохранёнными ключами: совпадений не было. Внешний Git-репозиторий не подключался.

Проверка версии 0.3: 39 серверных тестов и 4 теста отображения, проверка синтаксиса JavaScript. В браузере проверен запуск libphonenumber на вымышленном номере +12025550123, отображение обработанных данных и исходного JSON. Проверка DNS на вымышленном домене выявила частичные таймауты резолвера: такой ответ помечается незавершённым, без утверждения «Ничего не найдено». Пустые успешные ответы проверены автоматическими тестами. Все пять Docker-контейнеров запущены; каталог показывает 18 доступных к запуску утилит. Это проверка доступности, а не успешности запросов ко всем внешним источникам.
