# Исправление обработки PhoneInfoga — 27 октября 2026

Причина: адаптер извлекал Google-ссылки из консольного вывода в сущности графа и пропускал поля сканера local. Сформированные поисковые запросы увеличивали число объектов, хотя страницы по ним не проверялись.

В нормализаторе 1.1 поля raw_local, local, e164, international и country_code извлекаются в структурированный JSON и сведения источника. Страна помечена страной нумерации. Google-запросы вынесены в отдельный сгруппированный список с декодированным запросом и названием сайта, без добавления в граф. Исходный stdout сохраняется без изменений. Отсутствие локальных полей отмечается частичным результатом.

При старте приложения сохранённые успешные ответы старого формата перерабатываются один раз, с сохранением времени получения. Для нового адаптера используется отдельная версия кэша.

Проверено: 22 автоматических теста прошли, оба сохранённых запуска переработаны без сетевых запросов, поисковых узлов в их графах нет. Новый запуск PhoneInfoga в Docker на вымышленном номере +1 202-555-0123 вернул пять локальных полей, 45 поисковых заготовок и единственную сущность страны нумерации. Контейнеры app и phoneinfoga обновлены.
