# GeoLite: совместимость с geoip2 5.1

Причина ошибки обработки при наличии локальных баз: адаптер использовал удалённое свойство `record.raw`. В установленной версии `geoip2==5.1.0` модели City, Country и ASN сериализуются методом `to_dict()`.

Исправлено преобразование прочитанной записи. Расположение баз, ключи и история не изменяются. Ошибочные исторические запуски остаются в истории; для получения данных нужно выполнить новый запуск.

Добавлены три теста: сериализация реальных моделей v5 для трёх типов баз (включая координату 0 и сеть ASN), отсутствие IP в базе и отсутствие самих баз. Прошли 52 серверных теста. На установленных MMDB проверено чтение адреса `8.8.8.8` без сетевых запросов.
