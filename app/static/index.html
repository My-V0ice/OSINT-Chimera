Выберите файлы для поиска

Архив исключает файл из поиска. Его можно восстановить. Ничего не отправляется внешним сервисам.

Поиск без учёта регистра, е/ё и форматирования телефона. Точное совпадение проверяет целую ячейку. Файлы с разными заголовками ищутся вместе.
